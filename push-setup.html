Bayyin — push keys

Ye page aapke browser me hi 3 cheezein banata hai. Kuch bhi server par nahi jata. Neeche har cheez ke saath Copy button hai — Cloudflare me wahi paste karna hai.

Cloudflare me 3 variables

Worker → Settings → Runtime variables → Add variable → Name aur Value me ye paste karein:

VAPID_PUBLIC
…
VAPID_PRIVATE
…
VAPID_SUBJECT

Apna email badalna ho to yahan likhein (mailto: hata kar dekh lein — aage mailto: rehna chahiye).

Cloudflare me steps

  1. Worker → Settings → Runtime variables → Add variable.
  2. Pehli entry: Name VAPID_PUBLIC, Value = upar wala public key → Save.
  3. Dobara Add variable: Name VAPID_PRIVATE, Value = upar wala private key → Save.
  4. Teesri: Name VAPID_SUBJECT, Value = upar wala subject → Save.
  5. Upar Deploy dabayein. Phir worker ka URL khol kar check karein: {"ok":true,"vapidPrivate":"ok"}
