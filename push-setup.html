Bayyin — VAPID keys

Ye page aapke browser me hi ek key pair banata hai. Kuch bhi server par nahi jata. Keys banayein, phir public ko push.js me aur dono ko Cloudflare Worker ki settings me daal dein.

Public key (push.js me)

Private key — JWK (sirf Worker me, kisi ke sath share na karein)

Worker me kaise dalein

  1. workers.cloudflare.com → Create → Worker → worker/push-worker.js ka code paste karein.
  2. Settings → Variables: VAPID_PUBLIC, VAPID_PRIVATE (upar wala poora JSON), VAPID_SUBJECT = mailto:aapka@email.
  3. KV namespace banayein aur usay SUBS ke naam se bind karein.
  4. Triggers → Cron: 0 * * * * (har ghante; Worker khud local waqt dekh kar bhejta hai).
  5. Worker ka URL push.js ke ENDPOINT me aur public key PUBLIC_KEY me daal dein.
